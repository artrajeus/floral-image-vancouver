# Repository notes

This repo hosts the floral-image-vancouver site (index.html, survey.html,
video.html) and the **MXTology Claude CEO system** under `claude-ceo/`.

If you are a scheduled CEO session (Daily Brief, Weekly Kickoff, Weekly Review):
read `claude-ceo/CEO.md`, `claude-ceo/AGENT-ROSTER.md`,
`claude-ceo/OPERATING-RHYTHM.md`, and `claude-ceo/QUALITY-STANDARDS.md` first and
follow them.

**Before generating ANY pouch imagery in Higgsfield, read
`claude-ceo/POUCH-ELEMENTS.md` and follow its preflight.** It is the only
authority on which Element is current. Never select an Element by name, by
description, or by `created_at` — match the UUID and its `approved` status. If `claude-ceo/` is missing on the current branch, fetch and read it
from `origin/claude/ceo-agent-task-management-ckm6yi`.
