| Event | Dates | Where |

| Meredith | 11–13 Dec | Meredith VIC |

| Beyond the Valley | 28 Dec – 1 Jan | VIC — explicitly allows non-glass spirits |
| **Lost Paradise** *(new find)* | 28 Dec – 1 Jan | Glenworth Valley NSW — GA camping in every ticket |
| NYE on the Hill | 30 Dec – 1 Jan | VIC |

**Recommendation: one SKU, five sets of ad creative.** These events share the mechanic and overlap in time, so five separate event-branded SKUs would fragment inventory the way the Bash Pack already has (19 units stranded in a dead event's SKU). Run a single "Summer Festival Pack" and let the *ads and landing copy* name the event. Same conversion trick, no orphaned stock. Christmas post cutoffs make mid-December the real deadline — this needs building in November.
